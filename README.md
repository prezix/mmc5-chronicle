# MMC5 Chronicle / Летопись

Клиентско-серверный мод для приватной сборки **Medieval MC [NEOFORGE] MMC5**.

## Возможности

- русскоязычный журнал сюжета;
- интерактивная карта квестов и связей;
- трекер активных заданий;
- диалоги с сюжетными торговцами;
- отображение печатей, репутации и сюжетных меток;
- синхронизация с серверной системой FTB Quests.

## Совместимость

- Minecraft 1.21.1
- NeoForge 21.1.228
- Java 21

## Установка

1. Полностью закройте Minecraft.
2. Скачайте `mmc5chronicle-0.1.0.jar` со страницы Releases.
3. Поместите файл в папку `mods` профиля Medieval MC [NEOFORGE] MMC5.
4. Запустите игру.
5. Откройте Летопись клавишей **U**. Клавишу можно переназначить.

Мод не обязателен для подключения к серверу: игрок без него сможет войти, но не увидит интерфейс Летописи.
