# MMC5 Chronicle / Летопись

Клиентско-серверный мод для приватной сборки **Medieval MC [NEOFORGE] MMC5**.

## Возможности

- русскоязычный журнал сюжета;
- интерактивная карта квестов и связей;
- трекер активных заданий;
- диалоги с сюжетными торговцами;
- отображение печатей, репутации и сюжетных меток;
- синхронизация с серверной системой FTB Quests;
- карта JourneyMap не пропадает, если запись сервера в списке переименовали (начиная со сборки 15.11.2026).

## Совместимость

- Minecraft 1.21.1
- NeoForge 21.1.228
- Java 21

## Установка и обновление

1. Полностью закройте Minecraft.
2. Нажмите Win+R, вставьте строку и нажмите Enter:

```
powershell -NoProfile -ExecutionPolicy Bypass -Command "curl.exe -fsSL -o $env:TEMP\install-letopis.ps1 https://github.com/prezix/mmc5-chronicle/releases/latest/download/install-letopis.ps1; & $env:TEMP\install-letopis.ps1; exit $LASTEXITCODE"
```

3. Запустите игру. «Летопись» открывается клавишей **U** (клавишу можно переназначить).

Установщик берёт последний релиз, сверяет SHA-256 с GitHub, переносит старый `mmc5chronicle*.jar` в `mods-backup-letopis\<дата>` и кладёт новый в `mods` профиля Modrinth `%APPDATA%\ModrinthApp\profiles\Medieval MC [NEOFORGE] MMC5`. Другой путь к профилю: добавьте `-Profile "D:\путь\к\профилю"`. Только проверить версию, ничего не меняя: `-Check`.

Вручную: скачайте `mmc5chronicle-0.1.0.jar` со страницы [Releases](https://github.com/prezix/mmc5-chronicle/releases/latest), уберите старый `mmc5chronicle*.jar` из `mods` и положите новый.

Мод не обязателен для подключения к серверу: игрок без него сможет войти, но не увидит интерфейс Летописи.

## Пропали карта и метки JourneyMap

JourneyMap хранит карту в папке с именем записи сервера. После переименования записи или входа через другую (LAN, Radmin VPN) карта начинается с нуля, а старая остаётся рядом. «Летопись» при запуске игры объединяет такие папки в одну: карта и все метки возвращаются, ничего не удаляется, старые папки лежат в `journeymap\data\mp\_merged-<время>`. Подробности — в описании релиза.

## Для ИИ-агентов

Точный порядок установки, пути, коды выхода установщика и проверка после запуска описаны в разделе «Для ИИ-агентов и скриптов» [последнего релиза](https://github.com/prezix/mmc5-chronicle/releases/latest). Коротко: убедиться, что игра закрыта; запустить `install-letopis.ps1` и проверить код выхода (`0` — готово, `2` — игра запущена, `3` — нет профиля, `4` — не совпала сумма, `1` — ошибка); другие файлы в `mods`, `config` и `journeymap` не трогать.

## Список модов

Полный список модов клиента лежит в файле [`mods.txt`](mods.txt), один файл на строку.

## Проверка файла

Контрольные суммы всех файлов релиза — в `SHA256SUMS.txt` на странице релиза. SHA-256 мода в последней сборке:

```text
C15AF60D855573969FD67BC002A3C2669F39BB3702377BCE0D3F9BFB69863600
```
